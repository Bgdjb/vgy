# MEMO 3.0 — رفيق المذاكرة

## التشغيل على GitHub Pages
1. أنشئ مستودع جديد على GitHub وارفع **كل** محتويات هذا الفولدر (وليس الفولدر نفسه).
2. Settings ← Pages ← Source: `main` / root ← Save.
3. افتح الرابط على Android بـ Chrome ← القائمة ⋮ ← «تثبيت التطبيق».

## بيشتغل بدون إنترنت؟
أيوه بعد أول فتح (Service Worker بيخزّن الملفات). كل بياناتك محلية (IndexedDB) ومفيش أي تتبع.

## الموجود فعليًا
المساعد المحلي، القاموس (بحث عربي/إنجليزي، مفضلة، إضافة كلمات)، قارئ الدروس (اضغط أي كلمة)، مراجعة متباعدة (SRS)، اختبارات، دفتر الأخطاء، مهام + Pomodoro + وضع تركيز، مدرب مذاكرة، ركن هدوء، إحصائيات، نسخ احتياطي واستعادة.

## محتاج استكمال
- القاموس: 32 كلمة فقط (بيانات أولية تحتاج مراجعة معلم). أضف دفعات جديدة في `data/dictionary.json` بنفس الشكل.
- المناهج: `data/curriculum.json` فاضي عمدًا؛ لم يتم اختراع أي دروس.
- ربط ذكاء اصطناعي خارجي: غير موجود (الدالة `ask()` في `js/app.js` هي نقطة الربط).
- لم يتم تنفيذ: Mind Map، Spaced-writing، رسوم شهرية، IPA، CEFR، idioms/phrasal verbs.
